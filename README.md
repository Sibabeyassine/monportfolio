# Portfolio de SIBABE Yassine

Portfolio personnel réalisé avec Next.js, React et TypeScript.

## Démarrage

```bash
npm install
npm run dev
```

Le site sera disponible sur `http://localhost:3000`.

## Commandes

- `npm run dev` : serveur de développement
- `npm run build` : compilation de production
- `npm start` : serveur de production
- `npm run lint` : vérification TypeScript

Les textes et projets sont regroupés dans `app/page.tsx`. Le thème et la mise en page se trouvent dans `app/globals.css`.
